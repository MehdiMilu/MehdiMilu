MEHDI HASSAN MILU - GITHUB PAGES WEBSITE

UPLOAD
1. Create a public GitHub repository named exactly YOUR-GITHUB-USERNAME.github.io
2. Open the repository and choose Add file > Upload files.
3. Extract this ZIP on your computer first.
4. Upload index.html and the assets folder (including mehdi-profile.png) to the repository root.
5. Commit the changes.
6. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
7. Wait a few minutes and visit https://YOUR-GITHUB-USERNAME.github.io

IMPORTANT
- Replace the email placeholder in index.html before or after publishing.
- This is a public website. Do not upload private information.
- The WordPress theme is not needed for GitHub Pages.
- To update content later, open index.html on GitHub, click the pencil icon, edit, and commit changes.
